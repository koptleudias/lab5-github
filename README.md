# Веб-проект (Лабораторная работа №3)

## Назначение проекта
Проект представляет собой интерактивную веб-страницу с адаптивной семантической разметкой HTML5, кастомными стилями CSS3, подключенным шрифтом Sixtyfour Convergence из Google Fonts и скриптом JavaScript приветствия пользователя. Проект создан в рамках изучения практической работы с ветками по модели Git Flow.

## Настройка разработки
1. Откройте каталог проекта в VS Code:
   ```bash
   code .
   ```
2. Для просмотра веб-страницы в браузере откройте файл `index.html` напрямую или используйте расширение Live Server в VS Code.

## Руководящий документ
Управление ветками и разработка ведутся в строгом соответствии с инструкцией по работе с ветками (руководящий документ `lab_3.txt` / Git Flow).
